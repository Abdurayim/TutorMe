# Uzbek Translations Reference

This document contains all Uzbek translations used in the bot.

## Key Phrases

### General
- "Xush kelibsiz!" - Welcome
- "Iltimos" - Please
- "Muvaffaqiyatli" - Successfully
- "Xato" - Error
- "Tasdiqlaysizmi?" - Are you sure?
- "Bekor qilish" - Cancel
- "O'chirish" - Delete
- "Qo'shish" - Add
- "Tahrirlash" - Edit/Change

### Dashboard Messages
- "👑 Admin Boshqaruv Paneli" - Admin Dashboard
- "👨‍🏫 O'qituvchi Boshqaruv Paneli" - Teacher Dashboard
- "🎓 Talaba Boshqaruv Paneli" - Student Dashboard
- "O'qituvchilar:" - Teachers:
- "Talabalar:" - Students:

### Registration
- "Xush kelibsiz! Boshlash uchun telefon raqamingizni ulashing." - Welcome! To begin, please share your phone number.
- "✅ Ro'yxatdan o'tish muvaffaqiyatli! Siz endi Talabasiz." - Registration successful! You are now a Student.
- "👑 Admin sifatida ro'yxatdan o'tdingiz! Xush kelibsiz." - Admin registration successful! Welcome.
- "Bu telefon raqam allaqachon ro'yxatdan o'tgan." - This phone number is already registered.
- "Kiritilgan telefon raqam noto'g'ri." - The phone number provided appears to be invalid.

### Subjects
- "📚 Fanlarni Boshqarish" - Manage Subjects
- "Fanni tanlang yoki yangisini qo'shing." - Select a subject to manage or add a new one.
- "Hech qanday fan topilmadi. Birinchisini qo'shing." - No subjects found. Please add the first one.
- "📖 Fan boshqarilmoqda:" - Managing Subject:
- "Fan topilmadi." - Subject not found.
- "Iltimos yangi fan nomini yuboring." - Please send the name for the new subject.
- "Bu nomdagi fan allaqachon mavjud." - A subject with this name already exists.
- "✅ '%s' fani muvaffaqiyatli yaratildi!" - Subject '%s' created successfully!
- "Fan nomi muvaffaqiyatli yangilandi!" - Subject name updated successfully!
- "Fan nomini yangilashda xatolik. Bu nom allaqachon mavjud bo'lishi mumkin." - Failed to update subject name. It may already exist.
- "⚠️ Bu fanni va uning barcha kategoriya/resurslarini o'chirmoqchimisiz? Bu amalni bekor qilib bo'lmaydi." - Are you sure you want to delete this subject and all its categories/resources? This action cannot be undone.
- "🗑️ Fan muvaffaqiyatli o'chirildi." - Subject deleted successfully.
- "Fanni o'chirishda xatolik." - Error deleting subject.

### Categories
- "🗂️ Kategoriyalarni Boshqarish" - Manage Categories
- "Fan:" - Subject:
- "Hech qanday kategoriya topilmadi. Iltimos birini qo'shing." - No categories found. Please add one.
- "Kategoriyani tanlang:" - Select a category to manage:
- "📁 Kategoriya boshqarilmoqda:" - Managing Category:
- "Kategoriya topilmadi." - Category not found.
- "Iltimos yangi kategoriya nomini yuboring." - Please send the name for the new category.
- "✅ '%s' kategoriyasi muvaffaqiyatli yaratildi!" - Category '%s' created successfully!
- "Kategoriyani yaratishda xatolik." - Failed to create category.
- "Kategoriya nomi muvaffaqiyatli yangilandi!" - Category name updated successfully!
- "Kategoriya nomini yangilashda xatolik." - Failed to update category name.
- "⚠️ Bu kategoriyani va uning barcha resurslarini o'chirmoqchimisiz?" - Are you sure you want to delete this category and all its resources?
- "🗑️ Kategoriya muvaffaqiyatli o'chirildi." - Category deleted successfully.

### Resources
- "📚 %s dagi resurslar" - Resources in %s
- "Hech qanday resurs yo'q. Qo'shing!" - No resources yet. Add some!
- "Fayl (yuqorida yuborilgan)" - File (sent above)
- "Iltimos resurs havolasini yuboring (YouTube, ijtimoiy tarmoqlar va boshqalar)." - Please send the URL of the resource (YouTube, social media, etc.).
- "Iltimos fayl yuboring (PDF, DOC, video va boshqalar)." - Please send the file (PDF, DOC, video, etc.).
- "✅ Havola muvaffaqiyatli qo'shildi!" - Link added successfully!
- "Resursni qo'shishda xatolik." - Failed to add resource.
- "🗑️ Resurs muvaffaqiyatli o'chirildi." - Resource deleted successfully.

### Teachers Management
- "👨‍🏫 O'qituvchilarni Boshqarish" - Manage Teachers
- "Jami O'qituvchilar:" - Total Teachers:
- "👨‍🏫 O'qituvchilar Ro'yxati" - Teachers List
- "Hech qanday o'qituvchi ro'yxatdan o'tmagan." - No teachers registered yet.
- "Foydalanuvchi nomi:" - Username:
- "Telefon:" - Phone:
- "Telegram ID:" - Telegram ID:
- "O'qituvchi qilmoqchi bo'lgan foydalanuvchining telefon raqamini yuboring (format: +1234567890)." - Please send the phone number of the user you want to promote to Teacher (format: +1234567890).
- "Bu telefon raqamli foydalanuvchi topilmadi. Foydalanuvchi avval talaba sifatida ro'yxatdan o'tishi kerak." - No user found with this phone number. The user must register first as a student.
- "Bu foydalanuvchi allaqachon o'qituvchi." - This user is already a teacher.
- "Admin rolini o'zgartirib bo'lmaydi." - Cannot change admin role.
- "✅ Foydalanuvchi %s O'qituvchiga ko'tarildi!" - User %s has been promoted to Teacher!
- "✅ O'qituvchi Talabaga tushirildi." - Teacher has been demoted to Student.

- "🎓 Talabalar Ro'yxati" - Students List
- "Hech qanday talaba ro'yxatdan o'tmagan." - No students registered yet.

### Student Browsing
- "📚 Barcha Fanlar" - Browse All Subjects
- "Kategoriyalar va resurslarni ko'rish uchun fanni tanlang." - Select a subject to view its categories and resources.
- "Hech qanday fan mavjud emas." - No subjects available yet.
- "📖 Fan:" - Subject:
- "🔔 Siz bu fan uchun bildirishnomalarga obuna bo'lgansiz." - You are subscribed to notifications for this subject.
- "🔕 Yangi resurslar qo'shilganda xabardor bo'lish uchun obuna bo'ling." - Subscribe to get notified when new resources are added.
- "'Kategoriyalarni ko'rish'ni bosing va mavjud materiallarni o'rganing." - Click 'View Categories' to explore the available materials.
- "📁 %s dagi kategoriyalar" - Categories in %s
- "Hech qanday kategoriya mavjud emas." - No categories available yet.
- "Kategoriyani tanlang va resurslarni ko'ring:" - Select a category to view its resources:
- "📚 %s dagi resurslar" - Resources in %s
- "Hech qanday resurs mavjud emas." - No resources available yet.

### Subscriptions
- "🔔 Obunalarim" - My Subscriptions
- "Siz hali hech qanday fanga obuna bo'lmadingiz.\n\nObunalar yangi resurslar qo'shilganda bildirishnoma olish imkonini beradi." - You haven't subscribed to any subjects yet.\n\nSubscriptions allow you to receive notifications when new resources are added.
- "Yangi resurslar qo'shilganda siz ushbu fanlar uchun bildirishnomalar olasiz:" - You will receive notifications for these subjects when new resources are added:
- "🔔 Siz endi yangi resurslar uchun bildirishnoma olasiz!" - You will now receive notifications for new resources!
- "🔕 Siz endi bu fan uchun bildirishnoma olmaysiz." - You will no longer receive notifications for this subject.

### Notifications
- "🔔 Yangi Kontent Ogohlantirish!" - New Content Alert!
- "Fan:" - Subject:
- "Kategoriya:" - Category:
- "Yangi havola qo'shildi:" - New link added:
- "Yangi hujjat qo'shildi" - New document added
- "Yangi video qo'shildi" - New video added

### Errors and Permissions
- "Foydalanuvchi topilmadi." - User not found.
- "Sizda fanlarni boshqarish uchun ruxsat yo'q." - You don't have permission to manage subjects.
- "Sizda fan qo'shish uchun ruxsat yo'q." - You don't have permission to add subjects.
- "Foydalanuvchi ma'lumotlaringiz topilmadi." - Could not find your user record.
- "Telefon raqam formati noto'g'ri. Iltimos qaytadan urinib ko'ring." - Invalid phone number format. Please try again.

### File Size Limits
- "❗️ Fayl hajmi juda katta (>50MB).\n\nIltimos:\n• Video uchun: YouTube'ga yuklang va havolani yuboring\n• Hujjat uchun: faylni siqing yoki Google Drive havolasini yuboring" - File size too large (>50MB). Please: For videos: Upload to YouTube and share the link. For documents: Compress the file or share a Google Drive link.
- "❗️ Video hajmi juda katta (>50MB).\n\nIltimos YouTube'ga yuklang va havolani yuboring." - Video size too large (>50MB). Please upload to YouTube and share the link.
- "Iltimos hujjat yoki video fayl yuboring." - Please send a document or video file.
